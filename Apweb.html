🚀 CURSO PRÁCTICO DE HTML + CSS + JAVASCRIPT

Vamos a empezar desde cero absoluto. No necesitas saber programación.

La regla del curso será:
Cada cosa nueva que aprendamos la vamos a poner inmediatamente en práctica en una página web.
🟢 LECCIÓN 1 — Nuestra primera página web

🎯 Objetivo

En esta primera lección aprenderás:

  • Qué es HTML.
  • Qué es CSS.
  • Qué es JavaScript.
  • Cómo conectar los tres.
  • Cómo crear y abrir una página web.
  • Cómo hacer que un botón responda.

Todavía no vamos a complicarnos. Lo importante es entender cómo trabajan juntos.

📁 Paso 1: Crea tu primera carpeta

En tu computadora crea una carpeta llamada:

MiPagina

Dentro crea estos 3 archivos:

MiPagina/
│
├── index.html
├── style.css
└── script.js

Tu estructura debe quedar así:

📁 MiPagina 📄 index.html 🎨 style.css ⚡ script.js
⚠️ Importante si utilizas Bloc de notas

Cuando guardes los archivos, asegúrate de que realmente terminen en:

.html
.css
.js

y no en:

.html.txt
.css.txt
.js.txt

Si utilizas Guardar como, puedes seleccionar "Todos los archivos" y escribir:
index.html

📝 Paso 2: HTML

Abre:

index.html

con Bloc de notas y escribe:

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Mi primera página</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <h1>Mi primera página web</h1>
    <p id="mensaje">
        Hola, estoy aprendiendo HTML, CSS y JavaScript.
    </p>
    <button id="boton">
        Haz clic
    </button>
    <script src="script.js"></script>
</body>
</html>

Guarda el archivo.

🧠 ¿Qué acabamos de hacer?

<!DOCTYPE html>

Le indica al navegador que estamos utilizando HTML moderno.

<html>

Es el elemento que contiene toda nuestra página.

<html>
    Todo nuestro contenido
</html>

<head>

Contiene información de la página que normalmente no aparece directamente en la pantalla.

<head>
</head>

Por ejemplo:

<title>Mi primera página</title>

Es el texto que aparece en la pestaña del navegador.

<body>

Aquí colocamos lo que queremos mostrar en la página.

<body>
    Contenido visible
</body>

<h1>

Es un título.

<h1>Mi primera página web</h1>

<p>

Es un párrafo.

<p>Hola, estoy aprendiendo.</p>

<button>

Crea un botón.

<button>Haz clic</button>

🔗 Ahora viene algo MUY importante

Tenemos:

<link rel="stylesheet" href="style.css">

Esto significa:

"HTML, utiliza el archivo style.css para darle diseño a esta página."

Estamos conectando:

HTML ──────────→ CSS

Y tenemos:

<script src="script.js"></script>

Esto significa:

"HTML, utiliza el archivo script.js para ejecutar JavaScript."

Estamos conectando:

HTML ──────────→ JavaScript

Por eso nuestra estructura es:

index.html │ ┌────────┴────────┐ ↓ ↓ style.css script.js 🎨 ⚡ Diseño Interacción

🎨 Paso 3: CSS

Ahora abre:

style.css

Escribe:

Guarda.

🧠 Entendamos CSS

CSS utiliza esta estructura:

selector {
    propiedad: valor;
}

Por ejemplo:

h1 {
    color: blue;
}

Significa:

h1       → ¿A quién quiero modificar?
color    → ¿Qué quiero modificar?
blue     → ¿Qué valor quiero poner?

body

body {
    background: #111827;
    color: white;
}

Estamos modificando toda la página.

background

Cambia el fondo.

background: #111827;

color

Cambia el color del texto.

color: white;

font-family

font-family: Arial, sans-serif;

Indica qué tipo de letra utilizaremos.

text-align

text-align: center;

Centra el texto.

padding

padding: 50px;

Crea espacio alrededor del contenido dentro del elemento.

Todavía no necesitas memorizar exactamente cómo funciona. Lo estudiaremos más adelante con detalle.

Diseño del botón

button {
    background: #2563eb;
    color: white;
    border: none;
    padding: 15px 25px;
    border-radius: 10px;
    cursor: pointer;
    font-size: 18px;
}
Haz que todos los botones tengan este aspecto.

:hover

button:hover {
    background: #1d4ed8;
}

hover significa aproximadamente:

"Cuando el mouse esté encima del botón..."

Entonces el color cambia.

⚡ Paso 4: JavaScript

Ahora abre:

script.js

Escribe:

const boton = document.getElementById("boton");
const mensaje = document.getElementById("mensaje");
boton.addEventListener("click", function () {
    mensaje.textContent = "¡El botón funciona!";
});

Guarda.

🧠 Entendamos JavaScript

Aquí empieza la programación.

Primero:

const boton = document.getElementById("boton");

Estamos buscando en HTML:

<button id="boton">

JavaScript encuentra ese elemento gracias a:

document.getElementById("boton")

Por eso HTML tenía:

id="boton"

Después:

const mensaje = document.getElementById("mensaje");

Busca:

<p id="mensaje">

Ahora JavaScript tiene acceso al párrafo.

👆 Detectar un clic

boton.addEventListener("click", function () {
});
"Cuando alguien haga clic en el botón, ejecuta lo que está dentro."

Y dentro tenemos:

mensaje.textContent = "¡El botón funciona!";

Esto cambia el texto del párrafo.

Antes:

Hola, estoy aprendiendo HTML, CSS y JavaScript.

Después:

¡El botón funciona!

🧠 Entendamos el HTML nuevo

1. <header>

<header>
    <h1>Mi página personal</h1>
    <p>Estoy aprendiendo desarrollo web.</p>
</header>

header significa encabezado.
Lo utilizaremos normalmente para colocar la parte superior de una página.

┌─────────────────────────────┐ │ HEADER │ │ Mi página │ └─────────────────────────────┘

2. <main>

<main>
    Contenido principal
</main>

main representa el contenido principal de la página.

Nuestra estructura ahora es:

HTML │ ├── HEADER │ ├── MAIN │ └── FOOTER

Esto es importante porque estamos empezando a organizar correctamente nuestra página.

3. <div>

<div class="tarjeta">
    ...
</div>

Un div es un contenedor.
Imagínalo como una caja:

┌───────────────────────────┐ │ DIV │ │ │ │ Todo lo que pongamos │ │ aquí está dentro │ │ │ └───────────────────────────┘

Más adelante utilizaremos muchísimo los div para construir diseños.

4. class="tarjeta"

Observa:

<div class="tarjeta">

Aquí estamos asignando una clase llamada:

tarjeta

La clase nos permitirá decirle a CSS:
"Quiero diseñar esta caja."

.tarjeta {
    background: white;
}

El punto . significa:
"Estoy buscando una clase."

5. <h2>

Ya conocíamos:

<h1>

Ahora tenemos:

<h2>

Los títulos HTML tienen diferentes niveles:

h1 → título principal
h2 → título secundario
h3 → subtítulo
h4
h5
h6

Por ejemplo:

<h1>Mi página</h1>
<h2>Sobre mí</h2>
<h3>Mis habilidades</h3>

No significa simplemente "tamaño de letra". Es una jerarquía de títulos.

6. <ul> y <li>

<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>

ul significa lista no ordenada.
li significa elemento de lista.

El resultado será:

• HTML
• CSS
• JavaScript

También existe:

<ol>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ol>

que produce:

1. HTML
2. CSS
3. JavaScript

7. <a> — enlaces

<a href="https://www.google.com" target="_blank">
    Visitar página
</a>

a crea un enlace.
href indica dónde queremos ir.

href="https://www.google.com"
target="_blank" hace que el enlace se abra en otra pestaña.

8. <br>

<br><br>

br crea un salto de línea.
Aunque existe, no debemos utilizar <br> para organizar todo el diseño de una página. Para eso aprenderemos CSS.

9. <footer>

<footer>
    <p>Mi primera página web - 2026</p>
</footer>

footer significa pie de página.
Normalmente contiene cosas como:

Copyright
Contacto
Enlaces
Información adicional

⭐ class frente a id

Observa:

<h1 id="titulo">

y:

<div class="habilidad">

La diferencia fundamental:

id

Identifica un elemento específico.

id="titulo"

class

Permite identificar varios elementos que pertenecen al mismo grupo.

class="habilidad"

Tenemos tres:

<div class="habilidad">

Por eso podemos aplicar el mismo diseño a las tres.

🧠 Ahora vamos a aprender CSS de verdad

1. Selector por etiqueta

body {
    background: #111827;
}

body es una etiqueta HTML.
También:

button {
    background: blue;
}

Esto significa:

Aplica este diseño a todos los elementos <button>.

2. Selector por clase

Tenemos en HTML:

<div class="habilidad">

Para seleccionarlo en CSS escribimos:

.habilidad {
    background: #111827;
}
⚠️ Importante
El punto:
.
significa clase.

Por ejemplo:
.tarjeta
.habilidad
.encabezado
.lista
son clases.

3. Selector por ID

Tenemos:

<h1 id="titulo">

Podríamos seleccionarlo mediante:

#titulo {
    color: red;
}

El símbolo:

#

significa ID.
Por ahora recuerda:

. → class
# → id

🧩 Selector combinado

.habilidad h3 {
    color: #60a5fa;
}

Esto significa:

Busca un <h3> que esté dentro de un elemento con la clase .habilidad.
<div class="habilidad">
    <h3>HTML</h3>
</div>

Por eso CSS encuentra ese h3.

⚡ Paso 4: JavaScript

Ahora abre:

script.js

Vamos a conservar la interacción anterior, pero añadiremos una segunda acción.
Escribe:

const boton = document.getElementById("boton");
const descripcion = document.getElementById("descripcion");
const titulo = document.getElementById("titulo");
boton.addEventListener("click", function () {
    descripcion.textContent =
        "¡Estoy construyendo mi primera página web!";
    titulo.textContent =
        "¡Mi página está cambiando!";
});

Guarda.

🧠 ¿Qué aprendimos de JavaScript?

Ahora tenemos tres variables:

const boton = ...
const descripcion = ...
const titulo = ...

Cada una guarda una referencia a un elemento HTML.

boton
  ↓
<button>
descripcion
  ↓
<p>
titulo
  ↓
<h1>

Después:

titulo.textContent = "¡Mi página está cambiando!";

modifica el contenido del <h1>.

Por tanto:

HTML ↓ Crea elementos CSS ↓ Los diseña JavaScript ↓ Los modifica
